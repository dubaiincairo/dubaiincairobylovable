محرك الحجز المباشر وتكامل المساعد الفندقي الذكي

بنية برمجية تركز على رفع نسبة التحويل ومطابقة معيار Yanolja Cloud Solution مع ألوان وهوية سويس بلو المعتمدة (#2b6fe8).

مسار الحجز وتزامن نظام إدارة الفنادق (PMS)

  • ✔ معرّف المصدر المباشر: كل طلب حجز يحمل المعرف WEB-DIRECT داخل نظام eZee Absolute لحساب العمولات.
  • ✔ تسعير مقارن مع وكلاء السفر OTA: إظهار شطب الأسعار وإبراز خصم الحجز المباشر ("وفر حتى 20% عند الحجز المباشر").
  • ✔ شريط الحجز الثابت: ويدجت علوي يتيح اختيار التواريخ وعدد النزلاء والبحث الفوري دون إعادة تحميل الصفحة.

المساعد الذكي وحماية معدل الطلبات عبر Upstash Redis

المنصة تدمج بين نموذج OpenAI gpt-4o ونموذج Google Gemini API لتقديم توصيات الغرف الذكية للنزلاء.

إعدادات حماية الخادم ومعدل الاستهلاك:
• الحد الأقصى لكل IP: بحد أقصى 20 طلباً في الدقيقة
• سقف الاستهلاك اليومي: حماية صارمة لمنع استنزاف التوكنز
• الخيار البديل التلقائي: Chatbase Widget الاحتياطي

محرك الإشعارات المزدوج (البريد الإلكتروني + واتساب)

تم تنفيذه في ملف src/lib/notify.ts باستخدام تقنية after() في Next.js لضمان سرعة استجابة فورية دون تأخير للعميل.

• التوظيف: careers@swissblue.sa (إرفاق السيرة الذاتية PDF)
