الطبقة 1: الكيان المؤسسي

محفظة الأعمال (Business Portfolio)

الطبقة 2: بوابة الربط البرمجي

مستخدم النظام والتطبيق (System User)

مستخدم برمجي داخل إعدادات الأعمال يمتلك مفاتيح وصول دائمة (EAFZCklo...) لا تنتهي صلاحيتها عند تغيير كلمات مرور الموظفين.

الطبقة 3: وعاء حساب واتساب

System User حساب نظام آلي مخصص للروبوتات البرمجية (whatsappapiswissblue). يمتلك مفاتيح API دائمة لا تنتهي عند تغيير موظفي الشركة لكلمات سرهم. إعدادات الأعمال ➔ المستخدمون ➔ System users.
Access Token (Bearer) رمز المصادقة الدائم الحامل للصلاحيات (EAFZCklo...). يمرر في ترويسة الطلب (Authorization: Bearer <TOKEN>) لاعتماد الإرسال. يولد مباشرة من صفحة مستخدم النظام System User.
WABA ID حساب واتساب للأعمال الحاضن للأصول (881895264727770). يضم القوالب، وطرق الدفع والفوترة، وسياسات الامتثال. إعدادات الأعمال ➔ الحسابات ➔ WhatsApp accounts.
Phone Number ID (الهدف) معرف كائن رقمي داخلي في ميتا (978544632005886). ليس رقم الهاتف. نقطة نهاية الإرسال الفعلية. كافة طلبات POST توجه حصراً إلى: /v20.0/{PHONE_NUMBER_ID}/messages. حسابات واتساب ➔ مدير واتساب ➔ تبويب Phone Numbers.
Display Phone Number رقم الهاتف الدولي المقروء (+966 50 707 4949). يظهر للعميل النهائي في تطبيقه مع علامة التوثيق الخضراء. شريحة SIM الفعلية أو الخط الافتراضي المعتمد.
الخطأ الأكثر شيوعاً عند المطورين: يقوم بعض المطورين بالخلط بين WABA ID وبين Phone Number ID. إذا تم إرسال طلب إلى الرابط https://graph.facebook.com/v20.0/{WABA_ID}/messages ستعيد ميتا خطأ HTTP 400 "Unsupported post request". يجب دوماً إرسال الرسائل إلى https://graph.facebook.com/v20.0/{PHONE_NUMBER_ID}/messages.
